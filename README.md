# 作业05：CNN模型实现与对比

## 一、作业内容
本次作业实现了两个卷积神经网络模型：
1.  极简 CNN 模型
2.  LeNet-5 经典模型

## 二、模型结构
### 1. 极简 CNN
- 1层卷积 + 1层池化 + 1层全连接
- 结构简单，计算速度快

### 2. LeNet-5
- 2层卷积 + 2层池化 + 3层全连接
- 经典的手写数字识别网络，特征提取能力更强

## 三、实验结果
- 极简 CNN 准确率：96.39%
- LeNet-5 准确率：98.79%

## 四、对比分析
LeNet-5 模型层数更深，特征提取能力更强，准确率比极简 CNN 更高。
